BlazeBox is a Nix flake for setting up and managing agents on a NixOS Linux system.

It's primarily centered around a containerized-first approach, but it also allows sessions to be moved between the host and the container.

Claude Code is the initial harness, but I'm looking to add more harnesses going forward.

---

I'm preparing the source code for release here, including making it less specific to my setup so it can be used more broadly. It should hopefully be released here soon.
